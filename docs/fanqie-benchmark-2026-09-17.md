# 番茄小说：内置模型与 ADB 完整任务实测

2026-09-17，Pixel 6 / Android 16，Mac 本机桥接。未编译或刷入 ROM。

## 已交付

1. **ADB 后端接入手机任务循环**：手机 APK 内的 `TaskLoop`、`VisionTaskModel` 发起模型请求，经带令牌的 localhost 桥接执行虚拟屏幕截图、点击、滑动、返回和等待。生产 Binder 后端仍拒绝未就绪的系统执行。
2. **计时及执行记录**：分别记录启动、观察、模型决策、动作、复核；保存本次页面、OCR、模型决定、页码及最终状态。任务结果保存在应用私有目录，重新打开应用可查看最近结果。
3. **连续读取与摘要**：模型负责选书、进入第一章，本地采集器连续翻页。页码必须从 1 连续递增，章节必须依次经过 1、2、3，直到第四章标题出现才标记完整；缺页、跳章、锁屏、购买或验证码提示均不能宣称成功。完成还必须经过新观察及模型复核。

## 模型与配置

经用户授权，从本机 `computer-use-kimi-demo/.env.local` 读取 DashScope 配置，未修改源项目。密钥未写进文档、代码或 Git；个人 debug APK 从忽略目录 `secrets/` 生成内置配置。首次导入后使用 Android Keystore 加密保存，原有自选模型不被覆盖，仍可编辑或切换。

默认模型：`qwen3.8-max-0902`，DashScope Chat Completions。依据官方通用/视觉旗舰定位和本账号实际可用性选择；不是对所有可用模型进行全面能力排名。参考 [阿里云视觉模型文档](https://help.aliyun.com/zh/model-studio/vision-model) 和 [思考模式文档](https://help.aliyun.com/zh/model-studio/deep-thinking)。当前任务使用非思考模式和 JSON 输出，降低延迟。

同一张应用首页截图的一次小样本：Qwen3.8-Max-0902 2.967 秒、Qwen3.8-Max 2.951 秒、Kimi-K3 4.257 秒。该测试只确认视觉接口可用和一次延迟，不能证明全任务能力优劣。

**内置真实密钥的 debug APK 仅供个人实验。APK 内置密钥可被提取；release APK 不打包该配置或桥接令牌。** 手机端加密存储不能改变这一点。

## 开发中实际暴露的问题

早期开发脚本遇到 OCR 合并按钮、反复滚动未展开分类、将封面当按钮、锁屏误判加载等失败，均不计为成功。修复了文字子串坐标、展开分类提示、加载等待、锁屏检测和页面序号检查。

第一轮完整 APK 测试 `20260917-191759` 连续读取了 60 页、约 100 秒完成正文采集，但最终 JSON 复核请求缺少服务商要求的“JSON”字样，被 HTTP 400 拒绝，最终 `FAILED`（108.944 秒）。已修复提示词，后续 113.189 秒运行才是完整成功结果。

## 使用方式

准备当前 Pixel 6 的 USB 调试连接，手机保持解锁。以下从项目根执行：

```bash
python3 platform/executor/prototype-virtual-display/probe.py build
mkdir -p build/validation
swiftc tools/benchmark/native/ocr.swift -o build/validation/droiduse-ocr
adb -s 设备序列号 reverse tcp:8765 tcp:8765
python3 tools/benchmark/server.py --serial 设备序列号
```

`adb` 不在 PATH 时使用 Android SDK 的 `platform-tools/adb`。本次 Mac OCR 可执行文件、原型包和令牌已经准备好。原型首次使用需安装构建出的 `probe.apk`（包含虚拟设备输入法）。源码全新检出时还需自行提供忽略的 `secrets/model.json`、`secrets/bridge-token` 并构建个人 debug APK；缺少这些文件时不包含内置密钥。

手机打开 **DroidUse → 任务 → ADB 实验 · 番茄小说**。空任务自动填入本次目标；模型可在「模型」页切换。电脑桥接服务必须运行。这是番茄小说专项实验入口，不是已验收的通用跨应用后端。

任务运行时助手页面保持亮屏；切到其他 App 后不强行维持用户屏幕。锁屏会停止本次实验，重新解锁后手动重试，不绕过锁屏。后台连续读取支持暂停/恢复及停止信号；暂停期间仍计入 4 分钟总预算。

## 边界与测试

- 虚拟设备配置独立显示、音频/相机策略，并仅对该虚拟设备撤销番茄小说录音权限；未修改主设备全局录音权限。检查服务存活、锁屏及用户在主屏打开番茄小说的冲突。这仍不是所有故障、音频焦点和所有 App 的生产隔离保证。
- 本任务通过分类点击完成，不依赖中文键盘输入，因此不证明独立中文输入已完成。
- 所有翻页与模型请求都有上限；错误不自动重发未知结果的操作。暂停、停止及页码门禁有本地测试；真实手机任务完整验收以本次证据为准。
- 本轮 Python 阅读/后端测试 15 项，Android 模型/循环单测 28 项；debug/release 构建、lint 均通过；Pixel 6 上 4 项设备测试全部通过；额外实测桥接暂停时动作阻塞、恢复后执行。最终 release APK 扫描确认不含真实 Key、内置配置或桥接令牌。

桥接服务有 240 秒会话上限，避免手机进程退出后实验显示无限保留。自动化手机测试结束后已重新安装最终个人 debug APK，并恢复本次成功运行的结果和记录；已实际打开手机结果页确认可见。
