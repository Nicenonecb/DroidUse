# 番茄小说全程纯视觉实验（2026-09-17）

## 实现与边界

新增 debug 入口“纯视觉实验 · 番茄小说”。使用同一手机本地 shell 执行进程与已配置的视觉模型，导航、正文阅读、翻页和总结均由模型看截图决定。`PhoneTaskExecutor(pureVision=true)` 不创建 PhoneOcr 实例，不调用 ML Kit/PaddleOCR，不提供 OCR 文字/坐标，也拒绝 read_chapters 自动阅读动作。

每次模型请求同时处理截图并给出动作。模型逐页报告页码、章节和简要内容；手机仅校验这些报告的顺序并保存与截图的对应关系，不在本地识别章节。完整性仍依赖模型对像素的理解，不等同于独立 OCR 或人工确认。最终另取新截图复核。

视觉模型使用 0–1000 归一化动作坐标，手机按截图尺寸换算为像素。检查范围、截图时效和后台显示的执行规则保留。动作只允许点击、滑动、返回和等待；当前原厂实验后端不支持独立文字输入，提示词已明确说明。模型保留选书记录及所有逐页内容摘要，而不是只保留最近几页。

原实验的 240 秒上限保持不变；纯视觉实验设置 600 秒和 100 步安全上限，以测量真实完成耗时，不能把超过四分钟的结果记为达标。shell 进程对显式预算也限制为最多 600 秒。运行仍在手机上，ADB 只安装启动和读取证据。

## 第一轮失败

`build/phone-benchmark/phone-run-91261254/`：模型识别出“都市脑洞”但像素坐标偏移，实际进入“三国”，随后多次重复点击搜索框。手动中止本轮，保留 abort.json；没有完成，不作为耗时成绩。修正明确的归一化坐标约定，同时补充后端不支持文字输入、错误分类应返回、连续两次无变化需换路线的指令。未引入 OCR 辅助或人工代替模型执行任务操作。
