# 能力清单与主屏隔离约束

状态：2026-09-17，阶段 1 设计基线；阶段 2/3 的实测结论见独立验证报告。本文要求不代表已经实现。

## 不可妥协的边界

正式基础 ROM 冻结后，日常迭代仅升级助手、执行服务和输入组件 APK。模型、提示词、业务任务与 API Key 不进入系统框架。冻结前必须验证权限、稳定接口和 APK 升级路径；新增功能如超出底层边界，调整方案而不是默认再次刷机。

主屏优先：后台不得抢主屏触摸、键盘、顶层焦点、音频焦点、媒体音量、输出路由、麦克风或相机。不能保证隔离时停止后台动作并返回 NEEDS_USER，不偷偷转到主屏。规则由系统机制约束目标 App，而非仅由 AI 自律。

后台默认静音且禁止音频焦点抢占、duck、全局音量/路由变更；不能仅给播放器音量设为 0 就宣称隔离。麦克风、相机默认禁止使用；录音、拍摄需用户主动接管。默认不读写用户剪贴板、不弹主屏通知、不发出振动。

## 能力范围

| 类别 | 必须提供的基础能力 | 后续按需能力 / 人工接管 | 隔离要求 |
| --- | --- | --- | --- |
| 观察 | 指定显示截图、尺寸/旋转、帧时间、前台窗口及任务信息 | 视频连续观察；受保护画面返回不可用 | 不默认采集主屏、不跨会话返回截图 |
| 触摸 | 点击、双击、长按、滑动、拖拽、取消手势 | 多指缩放/旋转/拖动需底层事件序列支持 | 绑定 displayId、frameId 与目标任务 |
| 输入 | 中文/英文/符号/多行提交；删除、替换、选区、光标、编辑动作 | 表情与不同输入法兼容 | 不抢主屏 IME，不依赖全局剪贴板 |
| 页面控件 | 点击/拖动组成日期、下拉、开关、数量等交互 | App 特殊控件适配 | 业务流程在 Agent，不新增专用 ROM 命令 |
| 导航 | 返回、启动应用、任务查询、明确目标的切换和关闭 | 前进、标签操作由页面实现 | 不把 HOME/最近任务全局按键当成后台局部导航 |
| 跳转 | 跟踪 Activity/任务及显示变化；阻止逃逸主屏 | 不兼容 App 暂停并交接 | 包括外部链接、分享面板、权限及文件选择器 |
| 文件 | 用户指定附件的受控传递、下载状态 | 文件选择与授权接管 | 不暴露全盘或任意私有 App 数据 |
| 音视频 | 后台静音播放可按业务需要允许 | 用户主动预览或接管 | 不抢焦点、不压低主屏音量、不改路由 |
| 麦克风/相机 | 后台默认拒绝、明确反馈 | 扫码、语音、拍摄交给用户 | 按隔离身份实施，不能全局关闭用户硬件 |
| 系统界面 | 识别并定位系统弹窗 | 登录、敏感权限、生物识别与支付由用户处理 | 不在主屏自动确认 |
| 运行状态 | 有界等待、超时、取消、停止、客户端死亡清理 | 断网重试、锁屏后由用户恢复 | 停止后拒绝迟到动作，失败不重放输入 |
| 接管 | 暂停、主动展示后台画面、交还后重新观察 | 前后台移动任务策略后续验证 | 交接期间只有一个操作者 |
| 性能 | 限制后台帧率、分辨率、任务数和资源预算 | 自适应降频/暂停 | 不能承诺零负载；主屏体验恶化时退让 |

## 系统与 APK 的职责

- **基础 ROM**：可更新执行组件的身份/权限、显示与任务控制入口；输入连接及共享资源的强制隔离机制；必要 SELinux 和稳定系统接口。具体修改点由实测决定，不提前承诺现成虚拟显示能隔离所有资源。
- **执行服务 APK**：会话、显示生命周期、动作队列、坐标转换、观察有效性、动作结果和接管管理。
- **输入组件 APK**：受控文本编辑，只能写入当前会话允许的目标。若系统只提供主屏输入连接，必须拒绝，不能“先抢焦点再恢复”冒充隔离。
- **助手 APK**：模型连接与多配置、任务规划、场景逻辑、进度和结果。模型只返回固定动作，不获得任意 shell 权限。

不能假定按包名/UID 的禁用就等于按显示隔离。同一 App 若同时供用户和 AI 使用，可能共享进程、UID、音频及剪贴板；正式设计必须明确禁止并行同包、使用独立用户/虚拟设备身份，或提供适当的系统隔离。该选择必须在 ROM 冻结前定案。

## 执行契约需要补充的内容

每个会话声明 displayId、目标应用/任务、实际能力和策略版本。每个动作带 frameId、显示几何、目标前提、唯一 requestId 和超时。固定动作应覆盖受约束触摸序列、文本编辑、局部导航及任务管理，不能提供通用系统调用。

补充结果：POLICY_DENIED、NEEDS_USER、TARGET_ESCAPED、INPUT_TARGET_MISMATCH、RESOURCE_CONFLICT；区分注入成功、页面变化与业务完成。显示销毁、锁屏或客户端死亡后废弃旧会话和帧。对资源拒绝要给出真实原因，不能伪造成功。

## ROM 冻结门禁

1. 主屏与后台跨 UID 运行时的输入、导航、弹窗和共享资源实测。
2. 输入/权限/文件选择及跨应用页面不能逃逸主屏；不支持则确定地暂停。
3. 后台请求音频焦点、播放、录音、拍摄与改变路由时，主屏播放/录音/相机仍正常，且拒绝策略能覆盖第三方 App。
4. App 权限和资源策略不得只在执行动作的瞬间生效；覆盖 App 自发启动的线程、服务和异步回调。
5. 停止、异常退出、USB 断开、锁屏与重启均释放资源，不重放操作。
6. 执行服务、输入组件和助手 APK 升级两轮，不修改系统镜像仍保持功能与策略。
