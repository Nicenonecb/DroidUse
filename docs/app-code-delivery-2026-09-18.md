# 应用功能代码交付与源码自查

按用户要求：只编写代码并阅读源码自查，不执行构建、测试、安装或真机验证。不能用历史测试结果代表本轮代码可运行。

## 本轮补充

- 中断恢复：RecoveryStore以Android Keystore AES-GCM加密保存原任务、模型配置ID、旧观察上下文和步骤回执；不复制API Key。恢复按钮加载原配置，创建新会话、获取新画面，先暂停请用户检查，再交回AI。没有旧动作重放队列。完成、主动停止或丢弃时删除加密记录。旧帧不作为完成证据；无法确认时继续人工处理，小说阅读证据可能需要重新采集。
- 人工输入：ROM和Phone运行后端都可进入人工查看；文字输入控件仅在当前帧支持text且有editorGeneration时显示，提交后清空。输入耗时导致旧帧过期时，重新观察并要求编辑代次、包名和display一致。界面不保存输入，人工观察不进入自动审计或恢复上下文。Phone原型没有独立输入连接，因此不会显示可用输入能力。
- 文件/照片：select_file_at支持已识别的系统DocumentsUI和Photo Picker包中的可见坐标选择，包括纯缩略图；点击前核对截图摘要。文件名targetId路径继续保留。第三方自定义界面的项目、目录和确认按钮通过已有tap/swipe/back操作，没有假装具备第三方文件数据接口。
- 系统资源动作：DeviceOperation、模型schema、参数校验、Binder传递及日志白名单已连接。相机/录音/媒体/系统面板/后台显示控制要求当前后端明确声明会话作用域能力。不会用主屏全局按键、剪贴板或音量修改替代。
- Binder手势序列化：补齐双击、长按、拖拽、双指轨迹；不再一律返回UNSUPPORTED。
- 普通任务完成条件：只有要求三章阅读的任务强制要求章节采集证据，其他任务仍通过新画面和模型复核确认完成。

## 操作类别与应用入口

| 类别 | 应用层实现路径 |
|---|---|
| 查看/理解/等待异常 | 截图、OCR、模型决策、新帧复核、结构化场景日志与人工处理 |
| 单击/双击/长按/滑动/拖拽 | Tap、DoubleTap、LongPress、Swipe、Drag；长按为有界手势，结束释放 |
| 多指缩放/旋转/移动 | MultiTouch双指轨迹 |
| 文本输入/编辑/输入法动作 | Text与EditorOperation；需要ROM编辑连接和当前代次 |
| 表单/日期/地区/数量/标签/返回 | 现有触摸手势和Back控制真实控件；无需为每种控件另造接口 |
| 应用管理/链接/分享 | open_app/open_link目标句柄，Back；app_home/app_restart/open_share需scopedActions |
| 文件/相册/上传下载 | 文件句柄、select_file_at、真实界面选择和确认；不虚构文件权限或上传完成 |
| 拍照/扫码/录音/视频拍摄 | DeviceOperation对应动作；相机、麦克风隔离未就绪则不开放 |
| 音视频控制 | 媒体控件可触摸；语义操作经DeviceOperation与后台资源声明 |
| 系统面板/设备状态 | scopedActions；真实主屏锁屏和网络中断不自动绕过，保留中断并从新现场恢复 |
| 身份/验证码/支付 | AskUser、人工安全窗口和独立输入，不绕过生物识别或自动确认支付 |
| 人工接管/停止 | 查看、触摸、文字输入、交回AI新观察、终止及资源清理 |

## 源码自查修正

已按模型解析→能力过滤→TaskLoop校验→后端派发→日志/恢复/人工操作路径阅读源码，修正：

1. 人工操作也检查display、坐标和编辑代次；Binder拒收主屏截图元数据。
2. 手动输入过期时重新核对同一个编辑连接，禁止直接使用旧帧。
3. 原子检查点完成后清空输出流引用，后续加密写入失败不会误删已完成检查点。
4. 纯视觉恢复保持原有frame.contextText JSON结构，通过独立恢复参考字段传入旧数据。
5. 普通任务不再受小说专用completionReady条件阻止；原有小说证据约束仍保留。
6. 敏感Binder观察进入人工流程，手动显示不交给模型；输入字段使用密码键盘与掩码。

系统边界仍明确：独立编辑连接、相机麦克风音频仲裁、系统面板隔离及具体App兼容性依赖ROM执行服务。应用侧不能通过声明接口让原厂系统获得这些能力。本轮没有运行时证据，不宣称所有App/选择器已兼容或性能已达标。
