# M3 本批实机验收

2026-09-24，Pixel 6/oriole，r8 构建时间戳 `1790234521`，A 槽。结论：**当前已实现的 M3 主要链路通过实机测试**，不等于整个 M3 规划完成或所有应用兼容性验收。

## 环境

- r8 保留数据 OTA 成功；设备安装的 Assistant/Executor APK 摘要与交付一致。
- 只恢复原工程 sepolicy 验证标记，保持 SELinux Enforcing；`coreReady=true`，测试结束 `activeSession=none`。
- 刷机后未联网，主动进入 Wi-Fi 设置并连接已保存的 `RedBearAI`（现场 SSID 大小写如此）。确认默认网络存在，手机访问 `https://www.baidu.com` 返回 HTTP 200。没有读取或保存 Wi-Fi 密码，没有据此宣称模型 API 测试完成。
- 测试仅使用合成文本/文件。合成下载文件与本轮 Wi-Fi UI dump 已删除；应用私有证据不提交仓库。

## 定位过的测试目标问题

最初配置计算器 `com.android.calculator2` 作第二应用，连续失败于“目标不存在”。检查锁定分支清单发现其主 Activity 为 `singleTask`，符合本批跨应用候选的主动排除规则。观察实际候选列表包含文件、短信、图库、录音机和音乐；改用已声明的音乐目标后往返测试通过。新增明确的候选断言，使以后配置不支持的目标时直接报告候选列表。

这不是任意应用切换均可用的证明。计算器作为初始 M2 目标的既有结果，与它作为 M3 跨应用候选被排除是不同场景。

## UI 检查与边界

- 重启桌面进程后，实机截图可见蓝熊壁纸、圆角方形图标及新版电话/短信/设置/通讯录/相机图标；未清除桌面布局数据。
- 系统资源查询确认圆角方形 mask，7 个品牌 overlay 启用。桌面“图库”快捷方式对应 `org.lineageos.glimpse`，仍显示其自身图标；r7 的 Gallery2 overlay 针对 `com.android.gallery3d`。不能把 overlay 启用计为两个图库应用都已换图标。
- 本批剪贴板限普通 TextView/EditText 纯文本、每条最多 4000 UTF-16 code unit；不接管原生长按菜单，不支持图片/文件剪贴板、WebView/Compose 编辑器。
- 尚未覆盖所有应用组合、跨应用编辑器之间粘贴、主屏剪贴板差分、超时故障注入和长期压力测试。已通过项不替代这些专项验证。
- 通知、权限修改、设置/连接/电源控制仍未开发；M4 电话与上下行音频另行推进。
