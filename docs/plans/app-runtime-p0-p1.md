# 应用运行层 P0/P1 实施与验收

用户要求：tiny 正式接入、独立任务服务、主屏资源调度、可追溯异常日志与安全恢复、完整动作接口、简单人工接管。禁止自动视觉兜底，未知结果必须暂停，不能记为成功。此清单是持续工作记录，不以编译通过代替真机验收。

## 1. OCR 正式流程（进行中）
- tiny 模型进入 main APK；统一原图像素坐标、文字框、可空置信度。
- 默认 tiny，页面可切换 ML Kit；任务开始固定引擎；不做静默回退。
- 延迟加载、两线程推理、串行识别、关闭幂等、异常回收 bitmap。
- 验收：主 APK 资源真机加载、中文/坐标/置信度/重复关闭；真实番茄链路完成49页/158.561秒，详见 runtime-service-validation-2026-09-17.md。

## 2. 独立任务服务（已接入，真机验收进行中）
- `TaskRuntimeService` 拥有执行循环、模型和执行器，页面通过本地 Binder 订阅状态及控制；返回 Home 和 CLEAR_TASK 重建页面时任务继续运行，已取得真机记录。
- 已加入停止通知入口、服务销毁释放、原子状态文件与进程中断检测；不自动重放。进程中断真机验证已执行；已加入3秒心跳/30秒租约；强杀后约31秒释放，并验证可以创建新会话。并非瞬时释放。
- 验收：Home、Activity 重建、任务移除、进程终止与重新进入。

## 3. 主屏资源调度（已接入，短时视频并行实测通过）
- tiny 两线程、引擎串行识别；保留单份当前帧，不缓存 Bitmap。截图间隔正常500ms，中度热/低电量1500ms；严重热、低内存、未充电且电量≤10%时 NEEDS_USER 并清理。资源变化写入 resource-events.jsonl。
- ResourcePolicy 单测覆盖阈值、充电不绕过热/内存保护、异常不调用模型/不提交动作。已完成主屏1080p30无声视频+40秒连续截图/OCR复测，采样无丢帧/焦点丢失；详见 ../video-concurrency-validation.md。音频及长时压力仍需补充。
- 任务结束释放模型、截图和执行会话；主屏播放视频同步实测，记录资源和卡顿证据。

## 4. 可追溯日志与恢复（进行中）
- 已分别记录截图/OCR/模型/执行耗时；增加task-journal、actions、frame-links，将步骤、动作和前后帧关联。审计写入失败停止提交。
- 新增敏感页面拦截、模型日志字段白名单、临时截图删除及已知密钥脱敏。限制与待办详见 ../task-audit-privacy.md。
- 区分网络、模型超时、执行器断开、无文字、按钮缺失、无变化、弹窗、加载失败、跨应用跳转。
- 已修复截图App标识写死的问题：按后台display读取实际恢复Activity，记录APP_CHANGED及帧包名。跳转出番茄后关闭批量阅读能力；弹窗识别仍待完成。
- 已接入模型scene结构化报告与脱敏日志：弹窗/加载/无进展及处理意图标为MODEL_REPORTED、verified=false，未验证真实App识别准确率。恢复新帧和过期帧拒绝有独立审计事件，决策日志写入失败不再继续执行。74项JVM测试、debug/release构建和lint通过。
- 敏感字段和敏感画面必须抑制/脱敏；密码、验证码、密钥不得落盘。
- 保存步骤检查点；恢复必须重新观察；结果不明确暂停保留允许保存的现场。
- 新增原子task-checkpoint文件，记录步骤号、最新帧、请求编号、回执状态及执行回执计数，不保存任务或输入原文。服务冷启动读取检查点并展示中断详情，PENDING/UNKNOWN_OUTCOME明确为结果未知、禁止重发。此项是中断信息恢复，并非进程退出后自动接续业务任务；旧会话和模型历史仍不恢复。
- 已修复动作回执异常时直接结束的分支：超时/连接异常记为UNKNOWN_OUTCOME并保留requestId，人工检查后以新帧继续，禁止自动重发。63项JVM测试及Pixel 6真实点击后注入超时验证通过；不等同于进程退出后恢复已完成。
- 不编写模型兜底策略；日志不能用未经验证的判断冒充真实故障原因。

## 5. 动作接口（进行中）
- 逐项覆盖用户动作表：观察；点击/双击/长按/按住释放；滑动/甩动/拖动；多指缩放旋转；文本输入编辑；键盘；表单；导航；应用管理；跨应用；文件；相机麦克风；媒体；系统面板；设备状态；等待异常；敏感确认；接管。
- 已加入 Frame.supportedActions、ActionCatalog，模型只收到允许动作的参数格式；TaskLoop 执行前再次校验。PhoneBridge 握手返回真实动作集合。
- 已接入 double_tap、long_press、drag；Pixel 6 隐藏屏幕 Lab 控件验证双击、长按和滑块拖拽通过。已进一步接入 multi_touch 两指轨迹，真机验证缩放、旋转、双指平移；其他动作类别仍待逐项实现和验证。
- 编辑/IME协议已接入：选择/光标、删除、全选、复制剪切粘贴、撤销重做、搜索/下一项/完成/发送/隐藏键盘；Binder逐项能力声明和编辑代次校验，Phone后端暂不开放。见contracts/ipc/README.md。
- 文件/应用/链接协议已接入任务层：select_file/open_app/open_link使用当前帧的后端候选句柄，校验动作类型、候选存在、能力声明，禁止模型传任意路径/URI/Intent。Binder已接入候选观察和提交序列化；Phone后端未实现，不向模型开放。68项JVM测试、构建与lint通过；真实文件选择与跨应用执行仍未验收。
- 实现现有后端能实现的动作，并逐项测试。受 ROM/系统权限限制的能力必须明确返回未就绪，不伪装支持；不得改动主屏共享资源绕过限制。

## 6. 人工接管（首版已接入，继续完善）
- 已接入暂停、等待步结束、安全窗口展示后台帧、人工点击/滑动/返回/刷新；手动操作不写入画面和输入日志。设备验证见 ../handoff-validation.md。
- 交回 AI 后取新帧继续；终止即释放，不重复旧动作。
