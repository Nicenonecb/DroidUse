# 开发里程碑

当前已完成开发版助手/执行服务 APK、模型配置和隔离协议库，以及独立的 ADB 虚拟显示原型：在 Pixel 6 / Android 16 上验证了隐藏显示、截图、定向点击和基础焦点隔离。APK 尚不能自主执行真实 App 任务；这些成果不代替 ROM 构建或完整助手验收，各里程碑仍未全部完成。详见[本轮交付报告](local-delivery-2026-09-17.md)。

2026-09-17 补充：后台能力清单已建立；扩展实验验证了长按/双指分发、部分弹窗与跨 App 跳转，发现后台中文输入、音频焦点、录音与相机隔离缺口。[专项报告](isolation-validation-2026-09-17.md)记录通过项、失败项及尚未覆盖的边界；共享资源隔离通过前不可冻结基础 ROM。

## M0：设备与构建链路

近期专项进展见[虚拟设备实测](virtual-device-validation-2026-09-17.md)：受控场景中已验证虚拟音频路由、资源申请拒绝及主屏不受影响；独立中文输入仍未通过。完整动作按 [115 项用例](acceptance-matrix.md)逐项验收，不能以单项成功替代系统门禁。

- 确认 Pixel 6（oriole）实机 BL 解锁、USB 数据、屏幕和电池状态。
- 准备 x86-64 Linux 编译环境，锁定 LineageOS 分支、源码 manifest 和匹配固件。
- 先编译未经修改的 ROM，再通过 Mac 刷机。
- 验证正常启动、Wi-Fi、安装 App、ADB/Fastboot 和目标应用人工使用。

验收：保存准确构建清单和可复现步骤；自编译系统能启动，目标应用基础使用情况有实测记录。

## M1：最小系统执行模块

- 内置独立系统执行组件、签名与调用者检查。
- 打通普通页面截图、点击、滑动、BACK/HOME。
- 实现最小助手测试页面和持续可用的停止入口。
- 验证权限、焦点变化、旋转、旧帧拒绝、取消和客户端退出。

验收：手机端助手能通过系统服务操作测试应用，全链路不依赖无障碍服务；未经允许的其他应用无法调用。

## M2：AI 完成一个真实任务

- 实现模型配置设置页，支持保存多套连接、连接测试与切换；服务地址、模型名称和 API Key 不写死。先打通一种实际选定的视觉模型协议，按实验需要增加其他协议适配，先支持文字任务输入。
- 加入模型动作校验、单步执行、结果再观察和失败退出。
- 实现中文输入，明确输入焦点管理。
- 建议首个任务：在一个购物应用中搜索指定型号，整理三个同规格候选；具体应用以 M0 兼容性结果为准。

验收：保存重复测试的任务结果、成功率、耗时、动作数和失败原因；不以单次演示替代稳定性验证。

## M3：跨应用比价

- 按京东、拼多多、淘宝实际兼容性逐一接入 GUI 任务。
- 统一商品规格、优惠条件、运费与来源记录。
- 输出可追溯候选表，支持用户跳转和接管。

验收：同款比价结果可人工复核，缺失信息明确显示为未知，不能查询的平台明确标注未完成。

## M4：外卖、酒店与语音

- 添加地址/预算/时间等任务条件。
- 外卖比较费用和配送条件；酒店比较日期、房型及取消条件。
- 加入语音入口与真实用户交互优化。

验收：用户可以在手机上发起、查看进度、停止和查看结果，电脑只参与开发与刷机。

后续本机实现：资源准入策略、六类故障监督、视觉任务循环和 Binder v2 观察客户端已完成代码与单测。系统资源钩子/编辑连接/截图与动作后端仍待接入，未将 M1/M2 标为完成。见[本轮实现](execution-loop-and-resource-gate.md)。
