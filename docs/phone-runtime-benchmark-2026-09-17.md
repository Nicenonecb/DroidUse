# 手机本地执行迁移与实测（2026-09-17）

## 最终结果

最新修正版本在 Pixel 6 上 **110.146 秒（1 分 50 秒）** 完成筛选、前三章连续阅读、摘要和复核。已安装手机。38 项 JVM 测试、9 项手机测试、debug lint、release 构建通过。此次单次耗时低于 4 分钟目标；此前失败与选书质量问题均保留在下文，不能把单次结果当成稳定成功率或与华为同条件比较。

## 运行结构

当前实验按钮使用 PhoneTaskExecutor。APK 执行本地中文 OCR、文字按钮定位、任务调度、连续翻页、页码与章节核验、结果整理；手机直接请求配置的云模型。手机 shell UID 执行进程创建后台虚拟屏幕，截取后台画面，发送指定 display 的点击、滑动与返回。运行期间无需 Mac Python 服务、Apple Vision、ADB 操作命令或端口映射。

原厂系统仍需要一次 ADB 启动 shell 进程；它不是普通 APK 自行获得 shell 权限。重启手机或执行进程退出后需要重新启动。未来 ROM 要提供启动、鉴权与完整系统隔离；生产 Binder 后端目前仍返回未就绪。此实验不证明独立中文输入、通用音频/麦克风/相机资源隔离已完成。

## 实现与验证

- PhoneOcr 使用随 APK 打包的 ML Kit 中文识别模型，截图放大两倍后本地识别，再将坐标映射回 720×1280。无需在线下载 OCR 模型。[Google 官方说明](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)。
- ReadingProgress 要求从第一章第一页开始、逐页连续、章节顺序连续，并看到第四章边界，才允许前三章完成。模型不能绕过证据门禁。
- PhoneBridge 仅监听手机 127.0.0.1，使用私有 token，限定番茄小说和动作集合，拒绝主屏目标，提供超时清理、会话取消与旧画面拒绝。它是调试实现，并非 ROM 资源钩子的替代品。
- 38 项 JVM 测试通过；9 项手机 instrumentation 测试通过，包括本地 OCR、真实章节标题回归、连续两次会话、暂停及取消。
- release 构建、debug lint 通过；release APK 不含默认模型密钥、bridge token、phone-executor.jar，已扫描确认没有实际凭据字节。

## 复现

```bash
python3 platform/executor/prototype-virtual-display/probe.py build
./gradlew :assistant:assembleDebug
python3 tools/phone/bootstrap.py --serial 设备序列号
```

随后在手机点击“手机本地实验 · 番茄小说”。运行不需要 Mac 继续发动作。收集结果：

```bash
python3 tools/phone/collect.py --serial 设备序列号
```

个人 debug APK 含用户授权的实验默认配置，不宜分发。模型配置仍可在手机桌面应用中修改。安装采用非增量模式，不依赖电脑持续提供 APK 数据。

## 失败样本与修正

首次手机端任务在关闭 Mac ADB 服务后仍自主导航、筛选并进入正文，但 46.524 秒时停止。OCR 将首章的“章”识别成“韋”，触发章节门禁，因此不计为成功。证据在 `build/phone-benchmark/phone-run-86782187/`，断开 ADB 服务的记录在 `build/validation/phone-disconnected-run.json`。

同页实机比较 1×、2×、3× OCR 后采用 2×，并补回归测试。另外首次选书虽评分较高，但简介写明慢节奏日常，偏离爽文目标；提示词已要求同时检查系统、升级、逆袭等爽文特征。OCR 仍可能错认人物名字，原始截图保留用于复核，不宣称全文无误。

## 修正后的完整任务

第二次实测由手机完成导航、51 页正文读取、摘要与模型复核，程序状态 COMPLETED，总耗时 **133.462 秒**（包含执行器初始化）。第 1 章页 1–17、第 2 章页 18–34、第 3 章页 35–51，第 52 页为第 4 章边界。证据：`build/phone-benchmark/phone-run-87313722/`。

书名《断更龙族后，我上综艺爆红全网》，详情页显示 8.5 分、95.6 万人在读、52.6 万字，分类包含都市脑洞、穿越、娱乐圈。手机截图 61 次、OCR 61 次、输入动作 55 次；OCR 合计 15.880 秒，截图合计 21.676 秒，输入合计 29.359 秒。云模型决策合计 37.945 秒、最后复核 5.949 秒；这些内部耗时与外层 action/observe 重叠，不应重复相加。

**人工复查发现推荐理由有误，不能把程序 COMPLETED 等同于全部需求验收通过。** 模型曾把邻书的“系统”标签归到本书；最后声称评分高于同页其他书，但同页另一本也是 8.5 分。详情页本书的文娱日常标签，也不足以单独确认用户期望的爽文。该次足以验证手机本地执行闭环和速度，选书质量仍需修正。已加强决策和复核提示：同书归属、同分并列、比较范围限制及明确爽文设定。

该轮 Mac ADB 保持连接用于事后/过程中只读取日志，无桌面桥接服务，无 reverse 映射；并未宣称物理 USB 拔除。审核记录：`build/validation/phone-runtime-audit.json`。首次失败样本则确实在关闭 Mac ADB 服务期间自主运行。

与用户描述的约 4 分钟相比，133.462 秒低于该时间，但任务选书不同、网络与起始状态不同，且存在上述选书质量问题，因此不能据此宣称全面超过华为。


## 选书约束与文字点击回归

加强选书约束后的第三次试验，31.880 秒停止于文字目标不匹配：OCR 将“直播签到”识别为“直擂签到”，模型给出的点击坐标准确，但目标字符串按正确汉字书写，被精确匹配拒绝。记录：`build/phone-benchmark/phone-run-87613556/`，不计为成功。

已增加 TextTarget：优先精确匹配；仅当目标中心在 12 像素以内、候选唯一、长度至少 6 且只有一个字符差异时容忍 OCR 错字，同时规范全角字符。短按钮、多个候选及不同位置不模糊匹配。新增 5 项回归测试，包含该实际书名误识别样本。


第四次试验选中明确带系统标签的作品，但 40.799 秒时首章再次被识别为“第1韋”，未读正文，不计成功。证据 `build/phone-benchmark/phone-run-87714857/`。实机对同一标题裁剪后分别以 1×、2×、3× 识别，3× 获得明确“第1章”。因此增加条件式标题局部识别：仅对疑似章节标题且全图未识别出“章”时，对标题区域重新 OCR；只有得到明确章节标题才替换该行。没有把“韋”直接改成“章”，页码和章节顺序门禁不变。该实际截图另增手机回归测试。


## 最终完整实测：110.146 秒

第五次试验使用上述全部修正，结果 COMPLETED，**总耗时 110.146 秒**，包含 APK 执行器初始化、后台环境建立、导航筛选、正文采集、摘要和最终模型复核。电脑仅启动任务与读取证据，任务操作和 OCR 全部在手机上，云模型仍通过网络调用。

选择《让你去心动6，你只跟姐姐打直球》。当时可见列表四本书的评分为 8.2、8.2、6.7、9.2；所选书为该可见范围内评分最高，不代表全榜最高。详情页显示 9.2 分、34.5 万字、已完结，以及都市脑洞、穿越、系统、直播标签。本轮未见在读人数，因此没有据此比较热度。正文第 10–11 页确实出现绑定“拿来吧你”能力复制系统，第 14–15 页出现身体强化礼包，支持系统开挂设定判断。

阅读证据：页码 1–39 连续，第 1 章对应页 1–15，第 2 章对应页 16–25，第 3 章对应页 26–39；第 40 页明确显示第 4 章。分页中可能包含上一章末尾，以上按页面章节标题归类，正文连续保留。模型复核通过，人工抽查了候选列表、详情数据和第四章边界截图。

前三章概要：林晨被母亲安排回国参加恋综，在节目准备期间绑定能力复制系统并获得身体强化；之后了解系统、查看嘉宾资料并期待录制；第三章进入节目录制，与另两位男嘉宾抵达心动小屋，引发直播观众讨论。完整摘要保存在手机任务结果及原始证据中。

- 证据目录：`build/phone-benchmark/phone-run-87865333/`
- 结果文件：`no_backup/task-result-87865284.json`
- 正文与截图：`no_backup/phone-run-87865333/reading.json` 及同目录 PNG
- 截图与 OCR 各 49 次，输入动作 43 次。手机截图合计 16.532 秒，OCR 合计 12.020 秒，输入合计 23.947 秒；云模型决策合计 29.770 秒，最后复核 8.739 秒。内部阶段与外层观察/动作耗时有重叠。

Mac 辅助基线为 113.189 秒、55 页；此次手机本地为 110.146 秒、39 页，书籍和页数不同，不能据此计算迁移带来的性能提升。迁移本身已完成实验运行时去电脑依赖，但尚需一次 ADB 激活，ROM 原生集成、后台中文输入和完整资源隔离仍未验收。
