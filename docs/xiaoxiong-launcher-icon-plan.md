# 小熊助手桌面图标形状计划

## 已确认的边界

- Pixel 6 当前默认桌面是 `com.android.launcher3/.uioverrides.QuickstepLauncher`。应用抽屉已显示「小熊助手」及新的白底彩色标志，但外轮廓仍被桌面绘制成圆形。
- Android 启动器负责给自适应图标应用统一遮罩；APK 可以提供图案、前景和背景，不能要求系统桌面对单个 App 保留指定的圆角方形外轮廓。
- 目前不刷 ROM，也不修改桌面全局图标形状。主 APK 的名称与彩色图案可以通过 `adb install -r` 更新。

## ROM 实施顺序（用户确认刷机后才进入写入阶段）

1. 在现有 Pixel 6 和对应 ROM 源码上记录 Launcher3 版本、图标缓存路径、桌面与抽屉截图；备份当前 ROM 包和可回退镜像。
2. 在 `packages/apps/Launcher3` 查找工作区、应用抽屉及文件夹图标的加载与遮罩路径。针对 `dev.droiduse.assistant/.MainActivity` 绘制白色圆角方形底板与彩色标志，保持其他 App 的图标行为不变；同时处理图标缓存失效与现有桌面快捷方式迁移。
3. 在与手机同版本的启动器上验证正常/深色主题、不同密度、图标长按、拖拽、文件夹、应用抽屉、重启后持久性和无障碍标签。若 Launcher3 的统一遮罩无法安全地按包名绕开，再评估 ROM 级默认启动器替换方案。
4. 编译 Launcher3 和整机 ROM，保存每次独立构建日志、退出码、安装包与 SHA-256；先在测试环境验收启动器更新和回退路径。
5. 刷机前按项目约定完成包校验、设备识别与必要备份，停在实际写入前等待用户明确继续。刷入后复测桌面图标、电话/Wi-Fi/相机等基础功能和 DroidUse 执行链路。

完成标准：手机重启后，默认桌面和应用抽屉中的「小熊助手」都是白底圆角方形，彩色标志清晰，其他 App 的图标形状不变。任何一步失败都回退到已保存的原启动器/ROM。
