# Kotlin 执行协议核心

这是实际可在本机编译的 Kotlin 库，不是已安装的系统服务，不会直接控制真实应用。

- `IsolationSession`：资源保护完整就绪才允许启动；启动确认前不能操作；保护过期、客户端退出、接管和取消均阻止新动作；必须确认目标停止且在途启动已取消后才能释放隔离。释放失败保持待清理状态。
- `IndependentEditor`：编辑目标限定非主屏、窗口与进程、连接代次；保留 Unicode 原文，拒绝无效 UTF-16 和超长请求；请求去重，结果不明时不自动重复输入。

- `IsolationCoordinator`：按项安装保护，全部确认才启动；失败、异常和过期走停止/排空/释放顺序，停止未确认时保留保护，支持清理重试。平台接口必须由真实 ROM 实现。

`ResourceGate` 提供带锁的资源准入策略；`ProtectionSupervisor` 把六类系统故障转成先拒绝、再停止/排空、最后释放。它们还没有接入 Android 资源服务。

除 ResourceGate 自身同步外，上述状态组件都由单一串行控制线程调用。时间参数必须是可信的单调时钟，保护证明必须来自 ROM 执行点，不能由 UI 或模型填写。Binding 只接受系统观测结果，不是外部 Binder 参数。应用侧需要 Binder 调用者/签名校验；本库不替代授权。

运行 `python3 platform/executor/runtime/test.py`。本机 Kotlin 2.3.10 / JDK 17 测试的是协议行为；Fake Platform 捕获文本仅证明文字未被编码破坏，不证明任意 Android App 已收到中文。`Android.bp` 给出 Soong 库集成声明，未在完整 ROM 树编译。

缺失的平台适配：系统保护证明及心跳、实际应用启动/停止/隔离回收、系统层保护服务死亡监听、独立编辑连接获取与客户端执行时校验。未接好之前不得实例化“永远返回就绪/成功”的生产适配器。一次 WMS 查询不能消除之后焦点变化的竞态，客户端提交时仍须验证连接代次与窗口所属关系。
